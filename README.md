# River of Life Academy website

Website for River of Life Academy (ROLA), a basic school in Accra, Ghana, running from Creche to Junior High School. Motto: Devotion and Service.

It is a static site: plain HTML, CSS and JavaScript. Open `index.html` in a browser, or host the folder on any web host.

## Pages

| Page | What it holds |
|------|---------------|
| `index.html` | Home: welcome experience (opening photo, globe, tile wall), then an overview |
| `our-school.html` | Who we are, the motto, the Principal's welcome, the campus |
| `learning.html` | Creche and Nursery, Kindergarten, Primary, Junior High, curriculum |
| `school-life.html` | The school year as an expanding list, with photos |
| `admissions.html` | How to apply, what to bring, term dates, fees note |
| `moments.html` | Photo gallery |
| `contact.html` | Contact cards, message form, map |

## How the pages are made

The pages share one header, menu and footer. They are generated by `tools/build.py`, which holds those shared pieces and each page's content:

```
python tools/build.py
```

Change text in `tools/build.py` and run it to update every page. Editing an `.html` file directly also works, but the change is overwritten the next time the script runs.

## Other files

| Path | What it is |
|------|------------|
| `css/styles.css` | Base styles. Brand colours are the variables at the top |
| `css/experience.css` | Welcome screen stages, tile wall, preview sheet, menu |
| `css/pages.css` | Section pages, page transition, footer reveal |
| `js/site.js` | Shared behaviour: page transition, header highlight, expanding lists |
| `js/main.js` | Welcome experience, menu, gallery, form. Tile text is in `TEXT_CARDS` |
| `images/site/` | Colour photos used on the pages, plus `crest.png` |
| `images/globe/` | Black-and-white tiles for the globe; `full/` holds the colour versions shown in previews |

## Common changes

- **Home background video:** save a short muted clip as `images/site/hero.mp4`. It replaces the changing photos automatically.
- **Swap a photo:** replace the file in `images/site/` with a new one of the same name.
- **Contact details:** set `PHONE_DISPLAY`, `PHONE_LINK` and `EMAIL` at the top of `tools/build.py`, then run it.
- **Term dates:** edit the rows in `page_admissions` in `tools/build.py`.
- **Contact form:** it opens the visitor's email app by default. To receive messages directly, create a form at formspree.io and paste its address into `FORM_ENDPOINT` in `js/main.js`.
