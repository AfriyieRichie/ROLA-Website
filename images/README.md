# Images

- `site/` : colour photos used on the pages (cropped and resized from the school's own photos).
- `globe/` : black-and-white cards for the welcome-screen globe (`t01.jpg` to `t22.jpg`).
- `originals/` : the untouched screenshots the above were made from. Keep these on your
  computer but do not upload this folder with the website (it is about 170 MB).

To swap a photo, replace the file in `site/` or `globe/` with a new one of the same name.
